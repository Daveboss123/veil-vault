# Generated art inbox

Place original, highest-resolution image exports here after generating them from
the prompts in `docs/ART-BRIEF.md`.

Do not place API keys, wallet screenshots, addresses, receipts, recovery
phrases, salts, private move files or unrelated personal images in this folder.
The originals will be reviewed and converted before the app references them.
This folder is deliberately outside `public/`, so source exports are not shipped
with the website.
